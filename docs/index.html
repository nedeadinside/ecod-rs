ecod-rs benchmark

ecod-rs is a Rust implementation of the ECOD outlier detector (Li et al., 2022) with Python bindings. Here it is compared with ECOD from PyOD.

Data is random normal noise of several sizes (rows x features) and the classical datasets from ADBench. Each dataset is split 60/40 into train and test. Every measurement runs in a fresh single-threaded process, times are taken over 5 runs.

What is measured:

  • fit: training, including conversion from numpy;
  • score: scoring the test part with a fitted model;
  • pipeline: fit and score together;
  • convert: passing data into ecod-rs up to input validation;
  • save and load: writing and reading a model file. The default and compressed variants are zstd levels 3 and 19 for ecod-rs, joblib levels 0 and 3 for PyOD.
